# Raw Assets

Archive for asset concepts, reference images, comparison visuals and review screenshots.

- `concepts/2026-10-11_18-43-13_-0700_workshop-asset-options.png`: the approved sheet of 24 separated asset ideas.
- `concepts/2026-10-11_18-43-13_-0700_circular-pocket-workshop-reference.png`: the original circular workshop reference.
- Future package folders: `<package-id>/YYYY-MM-DD-description-v01.png`, with later iterations saved alongside rather than replacing earlier images.

These are design references, not finished 3D assets. Approved GLBs and editor sources stay in `public/models/` and `public/models/editor-sources/`.

Package planning: [ASSET-PACKAGES.md](../../docs/ASSET-PACKAGES.md).

- `concepts/2026-10-11_18-43-13_-0700_workshop-package-scenes.png`: eight grouped package scenes, generated and archived with a Pacific-time timestamp.

Filename format: `YYYY-MM-DD_HH-mm-ss_-0700_description-v01.png`. For older references, the timestamp records archive time, not original creation time.
