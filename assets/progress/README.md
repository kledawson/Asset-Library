# Progress screenshots

Occasional snapshots of active work, organized by package. Shared interface work belongs in `asset-library/`.

Capture worthwhile visual changes using judgment: milestones, larger updates, and small but crucial refinements that help show the project’s evolution. There is no timed interval and no need to capture every text edit. For 3D assets, choose a clear angle, rotate and frame the object to show the change. Capture completed visual work when useful. Preserve earlier iterations and avoid duplicate unchanged views.

Filenames use Pacific local time and its actual UTC offset:
`YYYY-MM-DD_HH-mm-ss_-0700_description-v01.png` (use `-0800` during standard time).

Concepts and references remain in `assets/raw-assets/`; this folder records work in progress.
